An entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on [make.fun](https://make.fun/r/hv9zk8y5): exactly one funny line, written to `/output/entry.txt` — a joke that lands on a cold read, with no setup notes and no explanation.

> My GPS said, 'You have arrived.' I hadn't — but we both decided to pretend.

## How it works

`main.ts` (Node 22+) writes the single line to `/output/entry.txt` and validates it first: 1–200 characters, not only whitespace, exactly one line.

```sh
node main.ts
```
